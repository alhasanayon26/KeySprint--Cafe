# ⌨️ KeySprint -- Cafe

**A free typing practice website with a built-in code editor. No install, no sign-up, no build step. It's a single HTML file that runs in your browser.**

> *A little practice. A lot more speed.*

---

## ✨ What is KeySprint - Cafe?

KeySprint - Cafe is a typing practice app for anyone who wants to type faster and more accurately. It also includes **KS Code**, a small code editor where you can write, run and learn code without leaving the page.

Everything lives in one file (`index.html`). Your progress and settings are saved in your own browser, so there are no accounts and nothing to configure.

---

## 🚀 Features

### ⌨️ Typing practice

- **Timed tests:** Just Type, 15s, 30s, 1 min, 2 min, or a custom number of seconds
- **Many practice modes:** Words, Stories, Hard, Punctuation, Code, Quotes, Custom text, Lessons, Data Entry, Game and VS
- **Live stats:** a countdown, WPM and character count update while you type
- **Live speed graph** and an optional **live emoji** that reacts to how you are typing
- **Practice language:** choose the language you want to practice in
- **Restart quickly** with the Esc key

### 📈 Progress tracking

- Best WPM, accuracy, mistakes and characters typed
- Daily goal and day streak
- Speed-over-time chart you can open full size
- **Keys to practice:** shows the keys you miss most
- Badges and a full history table
- **Export your history to CSV**

### 🎮 Games and challenges

- **Falling-words game** to practice under pressure
- **VS mode** for head-to-head duels and tournaments
- **Certificates** and shareable result images you can download and share

### 🌐 Language and accessibility

- Full **English and Bangla (বাংলা)** interface, switchable at any time
- Light and dark modes with different colour styles
- Custom wallpapers with adjustable brightness
- Options for high contrast, bolder text, reduced motion and a dyslexia-friendly look
- Different caret styles
- A performance mode for slower devices
- Works on phone, tablet and desktop

---

## 💻 KS Code: the built-in code editor

Open **KS Code** with the `</> KS Code` button in the top-right corner.

- **Languages:** HTML, JavaScript, Python, C, C++ and Java
- **Run your code** with the Run button, **Ctrl + Enter** (Windows/Linux), **Cmd + Enter** (Mac) or **F5**
- **Output panel** with a live preview for HTML and a Log tab
- **Multiple tabs** with rename, open, save, export and copy
- **Find and replace** with case, whole-word and regex options
- **Undo and redo**, syntax highlighting, code suggestions and error highlighting
- **Ask AI chat:** ask coding questions, get code back, and insert it into your editor with one click. It also handles file attachments and images.
- **Expand buttons (⤢)** on the code box, the output box and the Ask AI box. Each one can fill the whole editor area on phone, tablet and PC.
- **Layouts:** Classic (2 columns) or Three columns (code, output, AI chat), with drag-to-resize online
- **Autosave** and a prompt to save your work before closing
- Wallpaper and glass styles (Normal, Frosted, Clear) that match the main site

## 📝 Notes

- **Your data stays on your device.** Progress, history and settings are stored in your browser's local storage. Clearing your browser data, or using **Settings → Reset**, will erase them. Use the CSV export to keep a copy of your history.
- **Internet connection:** typing practice works offline. The Ask AI chat and the online compiler for languages such as Python, C, C++ and Java need an internet connection.
- **Browsers:** the latest versions of Chrome, Edge, Firefox and Safari are recommended.
