About KeySprint - Cafe

KeySprint - Cafe is a free typing practice app. Test your speed, find the keys you miss, and get a little better every day.

  • WPM: every 5 correct characters count as one word.
  • Accuracy: the share of your keystrokes that were correct.
  • Modes: Words, Stories, Hard, Punctuation, Code, Quotes, Custom, Lessons and a falling-words Game.
  • Privacy: your results and settings are saved in this browser only. No account needed.

About KS Code

KS Code is a small code editor built into KeySprint - Cafe. Open it with the KS Code button at the bottom left.

  • Write HTML, JavaScript, Python, C, C++ and Java with colors, line numbers, suggestions and error marks.
  • HTML and JavaScript run right in your browser, even offline.
  • Python, C, C++ and Java run on an online compiler when you have internet. Without it, a small offline runner shows simple output only.
  • Use Undo, Redo and Run, or Ctrl+Z, Ctrl+Y and for Windows Ctrl+Enter, Mac Cmd+Enter. Turn suggestions, error marks and the online compiler on or off in KS Code Settings.
